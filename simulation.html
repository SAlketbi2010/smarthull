MODEL DOCUMENTATION

A transparent proxy, with explicit limits.

1. Mechanical reference

F = mg   ·   I = bh³/12
εmax = 3FL / (2Ebh²)
δ = FL³ / (48EI)
εg = εmax [1 − ℓg/(2L)]

Small-deflection, linear-elastic Euler–Bernoulli theory for a flat, simply supported rectangular beam under a center point load. The gauge strain is the spatial mean along a centered longitudinal gauge. Nominal modulus is an assumption, not a material certificate.

Specimen mass, load-head mass, roller friction, shear deformation, bonding compliance, temperature, creep, and plate effects are omitted. Broad or short specimens and large deflections need a more suitable model.

2. Synthetic optical response

Vs = 2(1 + d)e−k(εg + H) + ns
Vr = 2(1 + d) + nr
εratio = −ln(Vs/Vr) / k

Voltages in volts; strains in µε. Baseline gain is 2 V on both channels. Noise is Gaussian and independent. The assumed unloading offset is Hmax sin(πm/mmax), with zero offset at the endpoints.

This equation is a tunable surrogate, not a validated PMMA bending-loss law. Source splitting, coupling efficiency, photodetector gain, wavelength response, and ESP32 conversion must be characterized on the physical system. No ADC quantization is modeled.

3. Experimental workflow

Set geometry and optical assumptions, then run stepped loading and unloading. Acquisition takes independent synthetic readings at each load step. Elapsed interface time is not physical settling time.

Changing geometry or optical assumptions starts a fresh dataset. Source drift can be changed during acquisition to challenge the normalization. Calibration is fitted to gauge-average strain; validation uses a whole held-out cycle.

Test RMSE and R² describe this generated dataset only. Real validation needs physical measurements, independent reference checks, and repeated runs. Published FBG results remain literature context.
